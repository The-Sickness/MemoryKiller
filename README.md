## ✨ Features

### 📊 Live Memory Monitoring
See memory usage for every loaded addon in real time, so you can spot the resource hogs instantly.

### 🗑️ One Click Cleanup
Hit **Collect Garbage** to free unused memory right away. Great for long sessions or any time the game starts feeling sluggish.

### 🔄 Instant Refresh
Hit **Refresh** to pull the latest numbers, perfect after enabling or disabling addons.

### 🪟 Fits Your UI
Resize and move the MemoryKiller window anywhere so it blends with your setup.

### 💡 Helpful Tooltips
Hover over any button to see what it does and how it helps you manage memory.

***

## 📦 Installation

1. Download the latest release.
2. Extract the `MemoryKiller` folder into:
   ```
   World of Warcraft\_retail_\Interface\AddOns\
   ```
3. Restart WoW or type `/reload` in game.

***

## 🎮 Usage

Open chat and type:

```
/mk
```

The MemoryKiller window will pop up showing your addon memory usage.
